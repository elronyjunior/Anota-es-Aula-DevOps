Do commit ao ambiente de producao, etapa por etapa.

Etapas de uma pipeline

    Termos que aparecem no dia a dia

    Integracao Continua
    Cada alteracao enviada ao repositorio dispara build e testes automaticos.
    Entrega Continua
    O codigo aprovado fica sempre pronto para ir a producao, com uma aprovacao manual.
    Implantacao Continua
    O codigo aprovado vai para producao sem intervencao humana.
