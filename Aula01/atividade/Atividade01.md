# Atividade 01 - Organizacao inicial

## Objetivo

Preparar a base de trabalho da disciplina: repositorio no GitHub, padrao de organizacao das anotacoes e primeiro registro em Markdown.

## O que foi feito

1. Criacao deste repositorio para concentrar anotacoes, atividades e links dos projetos.
2. Definicao de um padrao de pastas que se repete em todas as aulas:

| Pasta | Conteudo |
|---|---|
| `AulaNN/conteudo/` | Material da aula e resumo tecnico |
| `AulaNN/atividade/` | Registro da atividade pratica |
| `projetos/` | Codigo dos projetos maiores, cada um preparado para virar um repositorio proprio |

3. Resumo da aula escrito em Markdown: [conteudo/README.md](../conteudo/README.md).
4. Realizacao da avaliacao diagnostica.

## Por que organizar assim

- Cada aula fica isolada: facil achar o material e a entrega correspondente.
- Projetos com codigo ficam separados das anotacoes. Assim cada um pode ter sua propria pipeline, historico e deploy sem misturar com a documentacao.
- O README principal funciona como indice, com uma tabela que liga tudo.

## Conceitos aplicados

| Conceito | Onde aparece |
|---|---|
| Repositorio remoto | GitHub como ponto central do codigo e das anotacoes |
| Markdown | Formato de todas as anotacoes, renderizado direto no GitHub |
| Padronizacao | Mesma estrutura de pastas em todas as aulas |
